# Changelog

## v1.0.0

First public version.

- Automatic clipboard history for text and images, deduplicated by content hash.
- Kind auto-detection for links, GitHub URLs, emails, hex colors, and code blocks.
- Manual "Add to clipboard" dialog with a required name, an optional description,
  and Link/Code/Image type chips that override auto-detection.
- Search, tabs (All, Pinned, Links, Code, Images), pin/unpin, and remove.
- Calendar & Reminders dialog: title, optional description, and a due date/time
  picker, with a tray notification when a reminder comes due.
- Always-on-top sticky note that auto-saves its text and remembers its position.
- Appearance settings: custom background image, dim level, and accent color.
- JSON export of the full history.
- System tray integration; closing the window hides it instead of quitting.
